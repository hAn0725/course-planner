# 课程表 · 学习计划

一个本地运行的课程与提醒工具，包含周课表、每日日程、课程导入、待办和重复提醒。

新安装时不会预填个人课程或作业。仓库中的导入示例均为虚构数据。课程、提醒和快捷网站只保存在当前浏览器的本地存储中；导入文本在浏览器本机解析。

## 日常使用

在 Windows 上双击「课程表」快捷方式，或运行：

```bash
npm install
npm start
```

应用默认打开 `http://localhost:3000`。也可以使用 `npm run dev` 启动开发服务器。

## 功能

- 周课表网格与每日日程视图
- 手动创建课程，或从文本、表格和日历文件导入
- 课程冲突检查与本地提醒
- 待办、截止日期、优先级和重复提醒
- 可在侧边栏添加并排序快捷网站，链接仅保存在本机
- 多语言界面

## 开发与检查

```bash
npm run lint
npm test
npm run build
```

项目使用 React、TypeScript、Vite、Tailwind CSS 和 Express。
