# 课程表 · 学习计划

一个本地运行的课程与提醒工具，包含周课表、每日日程、课程导入、待办和重复提醒。

新安装时不会预填个人课程或作业。仓库中的导入示例均为虚构数据。课程、提醒和快捷网站继续保存在当前浏览器中。原有文本和文件导入在浏览器解析；使用 AI 时，请求和相关数据会发送至所配置的模型服务。

## 日常使用

在 Windows 上双击「课程表」快捷方式，或运行：

```bash
npm install
npm run build
npm start
```

应用默认打开 `http://localhost:3000`。也可以使用 `npm run dev` 启动开发服务器。

## 功能

- 周课表网格与每日日程视图
- 手动创建课程，或从文本、表格和日历文件导入
- 课程冲突检查与本地提醒
- 待办、截止日期、优先级和重复提醒
- 可在侧边栏添加并排序快捷网站，链接仅保存在本机
- 多语言界面
- AI 助手：查询安排、创建提醒、课表截图草稿和学习计划，右侧提醒常驻

## AI 助手

默认模型为 `deepseek-flash`，关闭深度思考，不自动切换模型。已有 Windows 环境变量 `DEEPSEEK_API_KEY` 时直接使用；设置或更新变量后需要重新启动课程表服务。密钥仅由后端读取，不要写进前端代码、课表文件或 Git。

第一次发送前，页面会说明发送给 DeepSeek 的数据并让你选择是否允许。明确要求新增、且标题和日期时间完整的提醒直接保存，结果卡可撤销。课程新增、修改、删除，以及提醒修改、删除、完成，都需要在结果卡确认。删除课程会列出关联提醒；数据变化后需要重新检查预览。

可以粘贴课表文字，或上传 PNG、JPEG、WebP 截图（每次最多 4 张，合计 6 MB）。截图生成可编辑草稿；缺失时间或周次需要补全，重复课程不能直接导入，时间冲突会提示。截图、对话和 API 响应不在服务器落盘。

学习计划默认覆盖未来七天，09:00—21:00，每次 45 分钟，课程前后与学习间留 10 分钟；用户条件优先。计划会显示具体时段，点击“加入提醒”才保存。切换页面保留会话，刷新或新对话清空会话；已保存的课程和提醒保留。

服务端可选环境变量：`SCHEDULE_AI_BASE_URL`（默认 `https://api.deepseek.com`）、`SCHEDULE_AI_MODEL`（默认 `deepseek-flash`）。这些变量仅供后端配置；不要在 Base URL 中放密钥。`SCHEDULE_PORT` 可设置独立测试端口，默认仍为 3000。

每次请求最长 55 秒、最多 3000 输出 token；对话保留最近六次用户请求，最多五轮工具调用。失败或停止会保留输入和草稿；已执行的结果仍显示在操作卡中。撤销不会覆盖随后手动修改的目标。

真实 API 回归是显式运行的付费检查，普通 `npm test` 使用虚构数据和模拟接口，不产生 API 费用：

```bash
npx esbuild tests/aiLiveCheck.ts --bundle --platform=node --format=cjs --outfile=dist/aiLiveCheck.cjs
node dist/aiLiveCheck.cjs
```

默认连接独立测试端口 3001，可通过 `AI_TEST_URL` 指定。设置 `AI_TEST_FIXTURES` 为包含虚构 `weekly.png`、`dense.png`、`pending.png` 和 `fixtures.json` 的文件夹，可额外验证截图识别。沿用评估的十二个文字场景与三个截图场景，默认各重复两次（含截图共 30 项）；`AI_TEST_REPEATS=1` 可以仅做一轮检查。

## 用量与余额

左侧“用量与余额”显示 DeepSeek、Qwen、MiMo、GLM 余额，以及 Codex 剩余额度和 Token 统计。右侧提醒事项保持常驻。

DeepSeek 使用已有 `DEEPSEEK_API_KEY`。另外三家点击“连接”，在独立 Edge 窗口完成官方登录并打开余额页；读取成功后窗口自动关闭，之后自动读取。需要安装 Microsoft Edge。登录过期或出现验证时点击“重新连接”，无需手动填写余额。Qwen 显示阿里云账户资金，不代表 Qwen 独享余额；若官方只返回账户可用额度，页面会使用该名称。

Codex 复用本机 CLI 登录，读取官方额度与账户汇总；未安装 CLI 时需安装并登录，也可用后端环境变量 `SCHEDULE_CODEX_CLI` 指定已有 CLI 可执行文件或 `codex.js`。本机明细包括当前、归档会话，并按浏览器时区归组。两种来源分别显示，不重复相加。统计包含本机 Codex 实际使用的所有模型；缓存已包含在输入中，推理已包含在输出中，不再次计入总量。所选期间不被官方每日记录覆盖时，显示暂不可用。

页面先显示已有数据，再逐家更新；每分钟自动检查，也可点击总刷新或各厂商标题旁的刷新按钮。较慢的平台不阻塞其他结果。GLM 首次从控制台确认真实余额报告后，复用同一登录会话的只读报告接口，失败再回到控制台恢复；其余平台复用专用会话，后台跳过图片、字体和视频。厂商账单结算可能有延迟。读取失败保留上次结果，并区分成功读取和最近尝试的时间（精确到秒）。登录状态在 Windows 上使用当前用户 DPAPI 加密保存，应用退出时关闭后台浏览器。浏览器专用登录配置与规范化余额缓存位于 `%LOCALAPPDATA%\StudyDesk`，不进入仓库；不采集会话正文、其他软件或课程 AI 的用量，不计算费用。

只读接入验证（不调用模型，不产生推理费用，不输出密钥或金额）：

```bash
npx esbuild tests/usageLiveCheck.ts --bundle --platform=node --format=esm --packages=external --outfile=dist/usageLiveCheck.mjs
node dist/usageLiveCheck.mjs
```

详见 [用量页面说明](docs/usage-design.md)。

## 发布前检查

将准备发布的源代码加入暂存区后运行 `npm run check:publication`。该检查扫描暂存内容中的私有文件、常见密钥格式、用户绝对路径，以及当前进程中的密钥值；只打印文件名和问题类型，不打印敏感值。可用 `PUBLICATION_PRIVATE_MARKERS` 提供额外私有字符串，以 `|` 分隔。仍需人工检查提交差异及待推送历史，不能仅依靠字符串扫描。

不要上传 `.env`、浏览器登录配置、导出课表、截图、会话日志或私人缓存。新版本使用通用浏览器存储键，并在本机兼容读取唯一匹配的旧存储，旧数据保留备份。
