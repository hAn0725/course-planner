# AI 助手设计与数据约定

用户任务：在原有课程表旁查询安排、创建待办、识别课表和安排复习。左侧继续使用周课表与每日安排导航，加入 AI；右侧提醒常驻，窄屏在内容下方显示。沿用 frontend-design 与 oil-ui 的现有方向，不另设聊天产品皮肤。

视觉：深色侧栏 #18232b、背景 #f2f3f1、白色面板 #ffffff、正文 #202832、次要文字 #73808a、绿色强调 #527e45。字体沿用系统中文无衬线，正文 14px，操作 12–13px，Lucide 图标。主角是输入和实际操作结果；首屏用四个具体任务入口代替装饰性大图。布局保持左侧导航 / 中间助手 / 右侧提醒，文字左对齐。

状态：首次发送说明数据去向；未配置提供重启指引；生成中可停止；截图预览可移除；确认卡区分待确认、已保存、已取消和已撤销。课表草稿使用现有课程编辑器，未知数据不填默认教学周或学分。结果卡与提醒列表同时体现保存结果。进入、发送按钮反馈和确认状态切换使用短过渡；减少动态效果偏好下关闭。

可靠性：模型参数通过共享运行时校验后才到前端。查询与计划复用现有校历、课时周次和重复提醒规则。写入沿用原 LocalStorage 键；只在两个存储成功后回报保存。操作标识防重，确认前核对快照，撤销只恢复本次改动的记录。会话及草稿仅在内存中。

验收重点：1440px 桌面与 390px 窄屏的正文、操作卡和输入框；常驻提醒；课程草稿编辑再确认；创建、修改确认、撤销、切换和刷新；复杂周次、重复事项与计划避课。真实 API 回归与无网络单元检查分开，均使用虚构数据。
